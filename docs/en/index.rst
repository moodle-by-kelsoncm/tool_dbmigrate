Overview - moodle-tool_dbmigrate
================================

**moodle-tool_dbmigrate** is an administrative CLI tool for Moodle designed to perform platform **database migrations** between different DBMS engines (tested and validated for MySQL/MariaDB to PostgreSQL migrations).

Key Features
------------

- **Cross-DBMS Migration**: Transfers data from Moodle tables and sequences while preserving relational integrity.
- **Terminal Execution (CLI)**: Processes large data volumes without hitting web server memory or execution time limits.
- **Support for MySQL and PostgreSQL**: Production-tested and battle-proven.
