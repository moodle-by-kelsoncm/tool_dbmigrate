Visão Geral - moodle-tool_dbmigrate
===================================

O **moodle-tool_dbmigrate** é uma ferramenta administrativa CLI para o Moodle projetada para efetuar a **migração de banco de dados** da plataforma entre diferentes SGBDs (com suporte testado e validado de migrações MySQL/MariaDB para PostgreSQL).

Recursos Principais
-------------------

- **Migração Transversal de SGBD**: Transfere dados de tabelas e sequências do Moodle mantendo a integridade relacional.
- **Execução via Terminal (CLI)**: Processa grandes volumes de dados sem estourar limites de memória ou tempo do servidor web.
- **Suporte a MySQL e PostgreSQL**: Homologado para ambientes de produção.
