# moodle_tool_dbmigrate

> [!WARNING]
> **Repositório arquivado, sem manutenção / Archived, unmaintained repository.**
> O plugin não é mais mantido e não foi testado no Moodle 4.5 ou superior. O core tem o `tool_dbtransfer` (experimental), que migra entre bancos (inclusive MySQL para PostgreSQL) em *Administração do site > Desenvolvimento > Experimental > Migração do banco de dados* ou pela CLI `php admin/tool/dbtransfer/cli/migrate.php --help`.
> This plugin is no longer maintained and was not tested on Moodle 4.5 or later. Core ships the experimental `tool_dbtransfer`, which migrates between database types (including MySQL to PostgreSQL) at *Site administration > Development > Experimental > Database migration* or with `php admin/tool/dbtransfer/cli/migrate.php --help`.

New Moodle database CLI migration tool. Tested to migrate a database from MySQL to PostgreSQL, but, not restricted to this scenario.
